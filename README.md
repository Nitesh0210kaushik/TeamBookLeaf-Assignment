# BookLeaf Author Support & Communication Portal

Technical assignment for the Full-Stack Developer role at BookLeaf Publishing.

An author-facing portal and an admin (operations) portal for handling author support queries, with
AI-assisted ticket classification, priority scoring, and response drafting grounded in the BookLeaf
knowledge base.

## Repository layout

```
.
├── backend/    # Node.js + Express + TypeScript REST API (MongoDB / Mongoose)
├── frontend/   # React + TypeScript single-page app (Vite)
└── PROJECT_DOCUMENTATION.md   # Step-by-step build log and design decisions
```

Each app is an independent project with its own `package.json`, environment file and scripts.

> Setup instructions, architecture notes, AI design and API documentation are added as each part is built.
